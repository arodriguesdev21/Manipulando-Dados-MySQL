🎬 Queries MySQL

Este repositório contém uma coleção de exercícios em SQL baseados em dados de indicações ao Oscar.

Todos os exercícios e suas respectivas soluções foram organizados em um único arquivo .sql, onde cada questão está documentada em forma de comentário, seguida pela sua query correspondente.

🧠 O que foi praticado

Durante a resolução dos exercícios, foram aplicados conceitos importantes de SQL, como:

• SELECT, WHERE, ORDER BY
• GROUP BY e agregações (COUNT, MAX, SUM)
• HAVING
• Subqueries
• NOT EXISTS e NOT IN
• Filtros com LIKE
• Manipulação de NULL
• INSERTS

🎯 Objetivo

Praticar e consolidar conhecimentos em SQL através de uma base dados real, explorando diferentes formas de consulta e análise de dados.
